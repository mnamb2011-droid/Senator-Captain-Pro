# Senator Captain Pro — مشروع Android مستقل

هذا مشروع Android Studio (Java + WebView محلي) يحوّل واجهة الريموت إلى تطبيق APK مستقل.
لا يحتاج إلى Termux أو خادم Python أو تطبيق G-MScreen.

## البناء
1. فك ضغط الملف.
2. افتح مجلد `SenatorCaptainPro` في Android Studio.
3. انتظر Gradle Sync.
4. من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5. ستجد الملف عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## التشغيل
- الهاتف والرسيفر على شبكة Wi-Fi نفسها.
- افتح التطبيق وأدخل عنوان IP الصحيح للرسيفر.
- المنفذ المستخدم: TCP 20000.

## ملاحظات مهمة
- تم الحفاظ على أكواد الأزرار التي أرسلتها كما هي؛ لم يتم التحقق عملياً من خريطة الأكواد على جهاز الرسيفر.
- نجاح إرسال البيانات عبر TCP لا يثبت أن الرسيفر نفّذ الأمر؛ التطبيق يعرض نجاح الإرسال فقط.
- يجب اختبار الاتصال على موديل Senator Captain الفعلي. بعض إصدارات الرسيفر قد تتطلب handshake أو UUID مختلفاً.
- التطبيق لا ينفذ بث صورة/صوت؛ هو ريموت تحكم فقط.
